<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Repo deploy helper -> live gateway files | Helper mutates shared gateway only with backup and rollback. |
| Strava backend -> gateway | Backend is internal Docker HTTP endpoint, not public host port. |
| Smoke checks -> rollout | Gateway mutation is accepted only after tool allowlist smoke passes. |
| Runtime secrets -> logs/docs | Commands and summaries must not print `.env` contents. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-19 | Denial of Service | Shared MCP gateway | mitigate | Backup, atomic edit, config validation, smoke, and rollback on failure. |
| T-05-20 | Tampering | Gateway catalog/compose | mitigate | Temp-file tests verify exact preservation of existing entries and server list. |
| T-05-20a | Tampering | Cross-file gateway mutation | mitigate | Helper backs up both files, writes both from parsed YAML, restarts only after validation, and restores/restarts old config on any failure. |
| T-05-21 | Information Disclosure | Live secrets | mitigate | Runbook and helper avoid printing `.env`; secrets stay under `/opt/docker/mcp-strava/.env`. |
| T-05-22 | Elevation of Privilege | Gateway tool surface | mitigate | Smoke asserts expected read-only tools and forbidden sync/sql tools. |
</threat_model>
