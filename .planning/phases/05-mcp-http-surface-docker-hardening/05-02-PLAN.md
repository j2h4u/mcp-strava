<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Metric services -> local mirror | Services may read local SQLite and signal first-use freshness only. |
| Metric services -> downstream agents | Agents receive facts/metrics and must do interpretation themselves. |
| Metric services -> admin/runtime code | Services must not call sync, Strava, SQL escape hatches, token refresh, or logs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04 | Elevation of Privilege | Metric services | mitigate | AST guard rejects Strava/sync/runtime/token imports. |
| T-05-05 | Information Integrity | Fitness state payload | mitigate | Tests reject coaching keys and require registry metric ids. |
| T-05-06 | Information Disclosure | Workout details | mitigate | Return prepared metrics only; do not include raw Strava blobs or sync logs. |
</threat_model>
