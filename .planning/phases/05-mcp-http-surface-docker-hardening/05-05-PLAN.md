<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host persistent DB -> container | Container reads/writes only the explicit mounted mirror path. |
| Repo checkout -> live runtime | Live runtime uses `/opt/docker/mcp-strava`, not the dev checkout DB. |
| Container network -> public host | Backend is reachable by Docker gateway, not publicly published by default. |
| Secret file -> MCP surface | `.env` is runtime-only and must not enter responses/logs/tests. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-14 | Tampering | Runtime DB copy | mitigate | `prepare_runtime` validates source, backs up target, copies, then validates target. |
| T-05-15 | Denial of Service | Missing/invalid DB | mitigate | Container preflight fails closed and never creates an empty replacement DB. |
| T-05-16 | Elevation of Privilege | Container user | mitigate | Dockerfile runs as non-root uid/gid. |
| T-05-17 | Information Disclosure | Network exposure | mitigate | Default compose has `expose` only and no public `ports`. |
| T-05-18 | Information Disclosure | Secrets | mitigate | `.env` lives under `/opt/docker/mcp-strava/.env`, is ignored by docker build, and is never printed. |
</threat_model>
