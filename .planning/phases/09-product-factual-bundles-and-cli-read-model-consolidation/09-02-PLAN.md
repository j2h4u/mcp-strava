<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Product caller -> bundle service | CLI/MCP-facing parameters select bundle/date/sport/window behavior. |
| Bundle formatter -> product payload | Local facts become narrative-ready structured data. |
| Read model -> status facts | Threshold/category derivations become agent-visible facts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-02-S | Spoofing | bundle ids | mitigate | Accept only registered bundle ids from `AGGREGATE_METRIC_BUNDLES`; reject unknown ids before query work. |
| T-09-02-T | Tampering | bundle formatter | mitigate | Preserve metric ids/calculations from registry and do not synthesize unregistered metric ids. |
| T-09-02-R | Repudiation | status facts | mitigate | Include threshold/window/evidence/completeness fields and read-model metadata. |
| T-09-02-I | Information Disclosure | kudos/gear sections | mitigate | Keep kudos names detail-only and expose gear facts only from mirrored supported fields, not raw payloads. |
| T-09-02-D | Denial of Service | internal aggregate calls | mitigate | Use bounded bundle request sets and existing date/window validation. |
| T-09-02-E | Elevation of Privilege | MCP surface | mitigate | Reuse existing `get_training_aggregates`; add no MCP admin/sync/debug/raw tools per D-03/D-19. |
| T-09-SC | Tampering | npm/pip/cargo installs | accept | No package-manager install task exists in this plan set; keep package files unchanged. |
</threat_model>
