<threat_model>
Trust boundaries:
- Environment variables and `.env` file content are local configuration input.
- `.planning/config.json` may contain local GSD tokens and must stay outside runtime settings.
- `data/strava.db` and token files are local state referenced by paths only.

Threat register:
- T01 | Information disclosure | `.env` and `.planning/config.json` | Mitigated by testing that settings load path values and do not serialize secret contents into generated artifacts.
- T02 | Tampering | database path | Mitigated by validating path parsing without creating, deleting, or rewriting the database file.
- T03 | Denial of service | invalid port/freshness values | Mitigated by tests requiring clear exceptions for non-integer or out-of-range HTTP/freshness settings.
- T04 | Configuration confusion | multiple config sources | Mitigated by deterministic precedence: explicit environment mapping first, `.env` compatibility file second, defaults last.
</threat_model>
