<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI operator -> migration tooling | Local operator can intentionally run checks/migrations; commands must report clearly and backup before DDL. |
| Sync orchestration -> repository | Sync fetches external Strava data but persistence must be centralized. |
| Default tests -> durable mirror | Full test suite must not mutate real DB or call live Strava network. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-07 | Tampering | `db-migrate` command | mitigate | Require explicit command, backup before DDL, post-check, and parity status. |
| T-02-08 | Information Disclosure | operator SQL | accept | Keep local-only CLI command and prevent service/MCP reuse. |
| T-02-09 | Denial of Service | default tests | mitigate | Use temp/copy DBs only and avoid live Strava network. |
| T-02-SC | Tampering | package installs | accept | No package-manager installs are planned for this plan. |
</threat_model>
