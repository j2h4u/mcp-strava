<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Application modules -> SQLite adapter | Application logic should not acquire raw SQLite connections directly. |
| Sync ingest -> repository writes | High-volume stream writes can hold locks if not chunked deliberately. |
| Operator SQL -> application services | Arbitrary SQL remains a local CLI escape hatch, not a reusable service capability. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Tampering | repository writes | mitigate | Parameterized methods and explicit unit-of-work boundary; no generic SQL service method. |
| T-02-05 | Denial of Service | stream inserts | mitigate | Preserve chunked `executemany` and short commits. |
| T-02-06 | Elevation of Privilege | operator SQL | mitigate | Keep `cmd_sql` isolated to CLI and exclude it from repository/application/MCP design. |
| T-02-SC | Tampering | package installs | accept | No package-manager installs are planned for this plan. |
</threat_model>
