  <name>Pure metric functions in metrics.py</name>
  <files>src/mcp_strava/metrics.py, tests/test_metrics_pure.py</files>
  <behavior>
    calc_hr_recovery(rows) — rows are dicts {time_offset, heartrate, velocity}:
      - len(rows) < Config.Metrics.MIN_STREAM_POINTS → None
      - rows with no qualifying pause → None
      - rows with a >= MIN_PAUSE_SEC standstill (velocity < VEL_STOP) → HrRecovery with pauses_found >= 1,
        total_rest_sec > 0, median_rate not None
    calc_vertical_speed(rows) — rows are dicts {time_offset, altitude}:
      - len(rows) < Config.Metrics.MIN_ALT_POINTS → None
      - duration_hours < 0.05 → None
      - ascending altitude over sufficient duration → VerticalSpeed with vmh > 0, total_ascent_m > 0
    calc_cardiac_drift(rows, sport_type=None) — rows are dicts {heartrate, velocity}:
      - len(rows) < Config.Metrics.MIN_STREAM_POINTS → None
      - sufficient data → a CardiacDriftResult instance (drift_pct may be None on low quality)
    calc_hrr_pct(median_hr, hr_rest, hr_max):
      - any input None → None;  hr_max <= hr_rest → None
      - valid → round((median_hr - hr_rest) / (float(hr_max) - hr_rest) * 100, 1); calc_hrr_pct(150, 50, 200) == 66.7
  </behavior>
