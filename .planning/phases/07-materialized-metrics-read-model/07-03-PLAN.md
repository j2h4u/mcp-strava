<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Raw streams -> materialized activity facts | Expensive stream-derived metrics become persisted facts. |
| Dirty queue -> fact tables | Dirty rows decide what must be recomputed and cleared. |
| Metric version -> comparisons | Formula/version changes must remain visible in stored facts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-07 | Tampering | materializer dirty clear | mitigate | Failure-injection tests ensure dirty rows clear only after fact and audit commit. |
| T-07-08 | Information Integrity | metric versioning | mitigate | Versioned facts and tests prevent silent mixed-version comparison inputs. |
| T-07-09 | Denial of Service | materializer computation | mitigate | Bounded batch `limit` and optional lease-renew callback support long runs without request-path recompute. |
</threat_model>
