## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP request -> application service | Untrusted tool arguments must not trigger raw recompute or source mutation. |
| Read-model facts -> agent response | Stale/partial facts must not be represented as fresh complete metrics. |
| Metric-version facts -> period comparison | Comparisons must not silently mix incompatible metric versions. |
