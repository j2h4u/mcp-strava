<objective>
Convert two BIGINT-as-boolean columns to native BOOLEAN: `streams.is_moving`
and `activity_metric_facts.cardiac_drift_significant`.

Two independent sub-tasks in one commit. The registry-owned fact column
(cardiac_drift_significant) requires expanding the allowlist BEFORE changing the
metadata entry — the validator runs at import time and crashes startup if the
order is wrong.

The fingerprint auto-invalidation is expected behavior after this change:
`metric_registry_fact_column_sql.py` is in `COMPUTE_SOURCE_MODULES`, so changing
it flips `compute_logic_fingerprint()` → `_seed_logic_version()` detects stored
!= live → increments metric_version + mass-enqueues rematerialization on next
startup. This is correct and intentional — not a regression.

Purpose: Use native BOOLEAN semantics instead of 0/1 BIGINT conventions.
Output: Two columns with correct DuckDB types; updated write/predicate paths.
</objective>
