<objective>
Convert `refresh_requests.requested_for_day` from VARCHAR to native DATE.

The column is equality-filtered only — no range scans — so this is a clean type
upgrade with zero behavior risk. DuckDB returns `datetime.date` objects from
DATE columns; the existing `str(row["requested_for_day"])` call in
`pending_refresh_requests()` produces the identical "YYYY-MM-DD" string that
callers already expect.

Two callers of `enqueue_refresh_request` both pass ISO date strings derived from
`now.date().isoformat()` — change them to pass `now.date()` (a `datetime.date`
object) directly so the type change propagates cleanly.

Purpose: Remove string-typed date storage in refresh coordination table.
Output: refresh_requests table with native DATE column; clean call sites.
</objective>
