<objective>
Port the forgotten Hermes Walk discount: `WALK_TRIMP_DISCOUNT = 0.5` applied to the Walk-sport portion of daily TRIMP via per-sport daily aggregation, so `effective_trimp != observed_trimp` for days with walks. This both fixes inflated fatigue/ACWR/form and serves as the first real end-to-end proof of the zero-knob auto-recompute (editing this constant flips the fingerprint).

Purpose: An athlete who walks daily should not have walks counted at full TRIMP in the Banister load model.
Output: constant + pure fn + per-sport daily aggregation wired into the materializer's daily effective_trimp.
</objective>
