<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SQLite backup -> DuckDB migration | Weakly typed source data enters strong DuckDB tables. |
| Admin CLI -> storage migration | Local operator command can mutate durable storage paths. |
| Refresh runtime -> cutover gate | Active writer state determines whether migration may proceed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-02-01 | Tampering | `adapters/duckdb/migrations.py` | mitigate | Controlled casts, cast-failure reporting, table/count/coverage parity, and fail-before-final-write behavior. |
| T-08-02-02 | Denial of Service | cutover command | mitigate | Active refresh lease blocks cutover before target mutation. |
| T-08-02-03 | Information Disclosure | CLI output | mitigate | Output structured parity/paths only; no token values, raw stream payloads, raw SQL, or kudos names. |
| T-08-02-04 | Repudiation | rollback evidence | mitigate | Cutover report records pinned backup path and rollback instructions. |
| T-08-02-SC | Tampering | DuckDB dependency | mitigate | Depends on 08-01 package legitimacy gate before use. |
</threat_model>
