<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP/application params -> aggregate query builder | Untrusted product parameters must become enum-validated query choices only. |
| Registry metadata -> DuckDB SQL | Trusted registry definitions select whitelisted query templates. |
| Fact tables -> aggregate payload | Missing denominators and mixed versions must not be hidden. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-06-01 | Tampering | `aggregate_queries.py` | mitigate | Enum validation and registry-only query templates; no raw SQL/table/column parameters. |
| T-08-06-02 | Information Disclosure | aggregate response | mitigate | Exclude raw streams, raw payloads, table names, query plans, token state, and kudos names. |
| T-08-06-03 | Repudiation | aggregate provenance | mitigate | D-42 fields include calculation, aggregation mode, denominator, materialized timestamp, freshness, and metric-version status. |
| T-08-06-04 | Denial of Service | aggregate query path | mitigate | Prepared fact views/query builders avoid raw stream scans; performance gate follows in 08-08. |
| T-08-06-05 | Tampering | weighted metrics | mitigate | Missing denominator tests suppress weighted values or mark rows unavailable/partial. |
</threat_model>
