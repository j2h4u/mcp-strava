<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Application/refresh -> repository | Runtime callers can mutate durable mirror state only through repository methods. |
| Config path -> DB connection | A path string selects the durable database file. |
| Migration adapter -> runtime adapter | SQLite migration code must not become a runtime write path. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-03-01 | Tampering | `DuckDBRepository` | mitigate | Repository tests require parameterized methods and no generic SQL execution surface. |
| T-08-03-02 | Denial of Service | DB connection policy | mitigate | Expected DuckDB open fails closed and owner-mode is explicit for downstream topology. |
| T-08-03-03 | Tampering | runtime SQLite fallback | mitigate | Static guards allow SQLite only in migration/rollback code, not runtime writes. |
| T-08-03-04 | Information Disclosure | repository queries | mitigate | Runtime methods return product/fact data only; raw SQL, table names, and raw streams remain internal. |
| T-08-03-SC | Tampering | dependency chain | mitigate | Depends on 08-01 package gate and 08-02 migration parity before runtime use. |
</threat_model>
