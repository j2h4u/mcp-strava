<objective>
Close IN-03 from the Phase 10 code review: replace every `repo._fetchone` / `repo._fetchall`
call in `read_model_materializer.py` with named public methods on `DuckDBRepository`.

outside module (the materializer) crosses the adapter boundary, making the dependency
