<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Refresh runtime -> SQLite | All writes go through SQLiteRepository methods; no direct sqlite3 imports. |
| Refresh runtime -> Strava transport | Only via injected `StravaTransport` port; never via `db.py::api_request`. |
| Refresh runtime -> Clock/Sleeper | Determinism required for tests; runtime never reads wall clock directly. |
| Read runtime -> Refresh runtime | Read runtime may call `freshness.evaluate_freshness` and `enqueue_refresh_request_if_stale` only; it must not call `run_once`. |
