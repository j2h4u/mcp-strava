In `runtime.py`, implement:

```
def run_once(
    repo, transport, policy, clock, sleeper,
    *, owner: str = 'refresh-runtime',
    force: bool = False,
    mode: str = 'daily',
) -> RefreshResult | RefreshSkipped:
```

Orchestration:
  1. `acquire_refresh_lease(owner, expires_at=clock.now()+policy.lease_duration_seconds, now=clock.now())`; on False return `RefreshSkipped('refresh_in_progress')`.
  2. Read `refresh_state`; if `force` is False AND `last_success_at` is today AND `checkpoint_stage == Stage.complete.value`, release lease and return `RefreshSkipped('already_complete')`. When `force` is True, skip this short-circuit (D-15).
  3. If `state.backoff_until is not None` AND `state.backoff_until > clock.now()`, release lease and return `RefreshSkipped('refresh_delayed')` (applies whether `force` is True or False — D-15 preserves backoff discipline).
  4. Determine `current_stage`: if `state.checkpoint_stage` is a daily-cycle stage (or `complete`), start at `Stage.summaries` (or resume at `current_stage`). If `state.checkpoint_stage` is a backfill stage, raise `RuntimeError("incompatible checkpoint — backfill in progress, run run_backfill")` (defensive — should not happen because lease ownership prevents this).
  5. Iterate daily stages starting at `current_stage`: each stage calls a focused helper from `_sync_ops` that uses `transport.fetch(...)` and `repo.upsert_*` methods; after each successful stage call `set_checkpoint(next_stage, cursor)`.
  6. On `StravaUnavailable`, call `record_refresh_failure(now, reason=e.reason, backoff_until=clock.now()+resolve_backoff(e.reason, response_headers, policy))`, release lease, return `RefreshResult(status='failed', reason=e.reason)`.
  7. On full completion call `record_refresh_success(now)`, set `checkpoint_stage=Stage.complete`, append `sync_log` row with `{'mode': mode, 'forced': force}` audit payload, release lease, return `RefreshResult(status='ok')`.
