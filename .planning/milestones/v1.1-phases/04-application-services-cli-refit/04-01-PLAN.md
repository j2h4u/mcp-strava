<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Product service -> refresh runtime | Product services may signal locally but must not execute refresh runtime. |
| Product service -> Strava adapter | Product services must not import or call Strava network/token code. |
| Metadata -> consumer | Metadata must be factual and not encode hidden coaching policy. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Denial of Service | First-use refresh signaling | mitigate | `refresh_requests` dedupe plus tests proving repeated reads create one local request only. |
| T-04-02 | Elevation of Privilege | Product service registry | mitigate | Explicit allowlist excludes admin/debug commands; AST guard rejects sync/Strava imports. |
| T-04-03 | Information Integrity | Freshness metadata | mitigate | Separate refresh timestamp from last activity timestamp; tests cover both cases. |
</threat_model>
