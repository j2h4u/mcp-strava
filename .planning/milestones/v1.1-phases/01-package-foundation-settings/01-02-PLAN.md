<threat_model>
Trust boundaries:
- Environment variables and `.env` file content are local configuration input.
- `.planning/config.json` may contain local GSD tokens and must stay outside runtime settings.
- `data/strava.db` and token files are local state referenced by paths only.

Threat register:
- T01 | Information disclosure | `.env` and `.planning/config.json` | Mitigated by testing that settings load path values and do not serialize secret contents into generated artifacts.
- T02 | Tampering | database path | Mitigated by validating path parsing without creating, deleting, or rewriting the database file.
- T03 | Denial of service | invalid port/freshness values | Mitigated by tests requiring clear exceptions for non-integer or out-of-range HTTP/freshness settings.
- T04 | Configuration confusion | multiple config sources | Mitigated by deterministic precedence: explicit environment mapping first, `.env` compatibility file second, defaults last.
- T05 | Test pollution | cached settings singleton | Mitigated by keeping `load_settings()` stateless, adding `reset_settings_cache()`, and requiring tests that mutate environment to clear the cache.
</threat_model>

<feature>
  <name>Typed settings loading</name>
  <files>src/mcp_strava/settings.py, tests/test_settings.py, src/mcp_strava/db.py</files>
  <behavior>
    Defaults: empty environment with project root `/tmp/project` returns database path `/tmp/project/data/strava.db`, token path `/tmp/project/.env`, runtime profile `local`, HTTP host `127.0.0.1`, HTTP port `8000`, freshness warn age `12`, and freshness max age `24`.
    Overrides: `MCP_STRAVA_DB_PATH`, `MCP_STRAVA_TOKEN_PATH`, `MCP_STRAVA_RUNTIME_PROFILE`, `MCP_STRAVA_HTTP_HOST`, `MCP_STRAVA_HTTP_PORT`, `MCP_STRAVA_FRESHNESS_WARN_AGE_HOURS`, and `MCP_STRAVA_FRESHNESS_MAX_AGE_HOURS` override defaults.
    Env-file compatibility: a `.env`-style file containing those same `MCP_STRAVA_*` keys is accepted as an input source. Parsing preserves existing `load_env()` style: skip blank lines and lines whose first non-space character is `#`, split on the first `=`, preserve the value text after `=` without quote stripping or escape handling, and ignore keys outside the `MCP_STRAVA_*` settings namespace.
    Validation: invalid integer fields raise `ValueError` naming the invalid key.
    Cache behavior: `load_settings()` is stateless and accepts explicit inputs for tests; `get_settings()` is cached for runtime convenience; `reset_settings_cache()` clears the cache before tests that mutate process environment or default paths.
    Default root: when `project_root` is not supplied, infer the development repo root from `Path(__file__).resolve().parents[2]` in `src/mcp_strava/settings.py`; installed or Docker runtimes should set explicit `MCP_STRAVA_DB_PATH` and `MCP_STRAVA_TOKEN_PATH` in later phases.
    Freshness defaults: `12` and `24` are Phase 1 bootstrap defaults only; Phase 4 application freshness behavior may revise the policy when freshness is enforced in services.
  </behavior>
  <implementation>Add dataclasses `HttpSettings`, `FreshnessSettings`, and `Settings`; add `load_settings(environ=None, env_file=None, project_root=None)`, cached `get_settings()`, and `reset_settings_cache()`. Update `db.py` path resolution lazily: do not keep import-time `DB_PATH` and `ENV_PATH` as the source of truth. Add small helpers such as `_db_path()` and `_env_path()` that call `get_settings()` at use time, then update `DbConn.__enter__`, `load_env`, `save_env`, `refresh_token`, and API helpers that reference token/database paths to use those helpers while keeping existing auth function behavior otherwise unchanged.</implementation>
</feature>
