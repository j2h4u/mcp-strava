<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Shell args -> CLI dispatcher | User-provided command args select product/admin behavior. |
| CLI -> application services | Product commands expose service envelopes to stdout. |
| Admin command namespace -> local storage/runtime operations | Local operator commands can mutate refresh/storage state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-03-S | Spoofing | command registry | mitigate | Keep product and admin registries explicit; tests assert no admin names at root. |
| T-09-03-T | Tampering | admin storage commands | mitigate | Leave DB migration/cutover/sync/backfill only under `admin` with existing confirmation gates. |
| T-09-03-R | Repudiation | CLI output | mitigate | Product JSON emits ServiceEnvelope freshness/completeness/rationale/status fields. |
| T-09-03-I | Information Disclosure | CLI product output | mitigate | Product output uses shaped facts, not raw Strava payloads, SQL, token, or sync logs. |
| T-09-03-D | Denial of Service | product commands | mitigate | Product commands delegate to prepared read-model services and bounded aggregate services. |
| T-09-03-E | Elevation of Privilege | CLI/MCP boundary | mitigate | Keep admin functions unreachable from product registry and MCP tool allowlist. |
| T-09-SC | Tampering | npm/pip/cargo installs | accept | No package-manager install task exists in this plan set; keep package files unchanged. |
</threat_model>
