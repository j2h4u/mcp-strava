| Boundary | Description |
|----------|-------------|
| MCP client -> performance gate | Measurement must represent warm tool calls, not startup noise. |
| Query planner -> hot MCP reads | Query plans determine whether request paths can scan raw streams. |
| Live Docker runtime -> local mirror DB | Final validation can mutate runtime facts and must preserve backup/restore path. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-07-19 | Denial of Service | SQLite query shape | mitigate | EXPLAIN tests reject hot raw stream scans and non-index-friendly date filters. |
| T-07-20 | Tampering | live runtime validation | mitigate | Runbook and gates require pinned backup, preflight, migration, materialization, post-check, parity, and Docker smoke. |
