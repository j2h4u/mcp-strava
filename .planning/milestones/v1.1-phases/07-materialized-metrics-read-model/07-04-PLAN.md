<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Refresh runtime -> materializer | Long offline computation mutates fact tables under a writer lease. |
| Admin CLI -> live runtime DB | Operator command can mutate read-model facts and must preflight/backup where needed. |
| MCP tool registry -> operational controls | Agent-facing tools must not gain recompute/admin/dirty/status capability. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-10 | Denial of Service | refresh lease during materialization | mitigate | Runtime tests require lease renewal and fail-closed lost-lease behavior. |
| T-07-11 | Elevation of Privilege | MCP registry | mitigate | Forbidden-name tests reject materialization, recompute, dirty, status, admin, backfill, raw, SQL, and sync tool names. |
| T-07-12 | Tampering | admin materialization command | mitigate | Command uses preflight and repository boundary; live mutation remains below MCP and reports structured run metadata. |
| T-07-13 | Information Disclosure | admin output | mitigate | CLI output reports counts/status only, not raw stream rows, tokens, or arbitrary SQL. |
</threat_model>
