<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Source write API -> read-model invalidation | A local mirror mutation must create durable recompute work. |
| Semantic source hash -> source revision | Hashes decide whether facts are stale and must exclude non-semantic churn. |
| Refresh sync orchestration -> repository | Sync helpers must not split source writes from dirty enqueue. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-04 | Tampering | repository source writes | mitigate | Transaction tests inject failures and assert source plus dirty queue rollback together. |
| T-07-05 | Repudiation | source revision history | mitigate | `activity_source_state` records source hash, revision, activity day, and changed timestamp. |
| T-07-06 | Information Integrity | semantic hash computation | mitigate | Tests prove fetched/synced timestamp churn does not alter source hash. |
</threat_model>
