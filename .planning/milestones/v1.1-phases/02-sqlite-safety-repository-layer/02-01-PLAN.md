<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Filesystem -> SQLite adapter | Local DB path may be missing, corrupt, stale, or accidentally pointed at a fixture. |
| Migration tooling -> durable mirror | DDL can permanently alter `data/strava.db` if preflight/backup/parity are wrong. |
| Test fixtures -> real data area | Hermetic tests must not mutate the user's real mirror. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | `connection.py` | mitigate | Open expected DBs with fail-closed `mode=rw`; keep fixture creation explicit and test-only. |
| T-02-02 | Denial of Service | SQLite connection policy | mitigate | Set WAL, autocheckpoint, and busy timeout centrally. |
| T-02-03 | Tampering | `migrations.py` | mitigate | Require preflight, timestamped backup, post-check, and parity before marking migration successful. |
| T-02-04 | Information Disclosure | backup files | mitigate | Store backups under data area and apply local-user-only permissions where supported. |
| T-02-SC | Tampering | package installs | accept | No package-manager installs are planned for this plan. |
</threat_model>
