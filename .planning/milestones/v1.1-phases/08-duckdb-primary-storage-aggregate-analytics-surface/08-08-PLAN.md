| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-08-08-02 | Denial of Service | performance gate | mitigate | Six-tool warm p95 gate at 100 ms, startup measured separately by existing client behavior. |

| T-08-08-04 | Elevation of Privilege | MCP surface | mitigate | Smoke validates exact product tools and no admin/raw/sync/sql/debug tools. |
| T-08-08-05 | Tampering | rollback | mitigate | Rollback uses pinned SQLite backup, previous config, and a pre-cutover image tag such as `mcp-strava:pre-phase-8`; full Strava resync explicitly rejected. |
