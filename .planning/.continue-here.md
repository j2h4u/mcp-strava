## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| `rg -r` footgun | `-r` is ripgrep's `--replace`, NOT recursive. `rg -rln` / `rg -rn` replaces matches with the literal `ln`/`n` and mangles output. Recurred multiple times this session. | advisory | Use `rg -l` (files), `rg -n` (line numbers), `rg -c` (counts) — never `-r` unless you actually want replacement. |
| Asserting diagnoses without measuring | Earlier this session a "Docker contention" cause was fabricated without checking system load. | advisory | Measure first (system metrics, probes, logs), then state the cause. |
| `\| tail` masks exit codes | Piping a command whose exit code matters into `tail` reports tail's exit 0, hiding a real failure. | advisory | Don't pipe commands whose exit code you need; capture exit code directly. |
